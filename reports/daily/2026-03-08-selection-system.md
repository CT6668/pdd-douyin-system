## B. 评分模型（13维，权重合计=1.0）

### 维度定义与权重

| # | 维度 | 权重 | 自动/手动 | 说明 |
|---|------|------|----------|------|
| S01 | 拼多多热度 | **10%** | 自动（销量） | 月销量映射 |
| S02 | 近7天增速 | **10%** | 自动（7d vs 30d） | 增速信号 |
| S03 | 近30天趋势 | 5% | 规则推导 | 类目热度替代 |
| S04 | **抖音传播适配度** | **15%** | 规则推导 | 权重最高 |
| S05 | 视觉展示强度 | **10%** | 规则推导 | 视觉词匹配 |
| S06 | 低解释成本 | 8% | 规则推导 | 功能词反推 |
| S07 | 低决策成本 | 8% | 价格自动 | 价格带映射 |
| S08 | 价格带冲动消费度 | 8% | 价格自动 | 9.9-29.9满分 |
| S09 | 佣金价值 | **10%** | 自动 | 单件金额×比例 |
| S10 | 竞争难度（取反） | 5% | 规则推导 | 细分类目竞争估算 |
| S11 | 供给稳定性 | 5% | 规则推导 | 店铺关键词 |
| S12 | 合规风险（取反） | 4% | 规则推导 | 禁词检测 |
| S13 | 退货风险（取反） | 2% | 规则推导 | 品类特征 |

### 排序规则（非纯销量）

```
综合排序得分 = 抖音适配分×0.4 + 总分/10×0.4 + 佣金价值×0.2
```

> ⚠️ 严禁只按销量排序：销量高不等于抖音适合，高销量低佣金=无效劳动

### 入选门槛
- 总分 ≥ 60分 → 进入候选池
- 推荐进内容生成池：总分 ≥ 65 **且** 抖音适配分 ≥ 7

## C. 每日选品流程

```
09:00  ① 类目雷达更新
           → 搜索8个细分类目关键词（PDD API，sort_type=3销量）
           → 识别有高销量信号（含"万+"）的类目，标记 trend_7d=rising
           → 写入 category_radar 表

09:10  ② 候选商品池刷新
           → 对每个类目执行2次搜索（按销量+按佣金比例）
           → 过滤：价格9.9-99元 + 佣金率>0
           → 去重写入 product_pool（status=pending）
           → 目标：每日采集30-80条候选商品

09:30  ③ 13维自动评分
           → 自动维度：S01/S02/S08/S09（4个）
           → 规则推导维度：S03-S07/S10-S13（9个）
           → 计算加权总分，≥60分标记 selected
           → ✅ 人工节点：检查评分结果，可手动调整主观维度

10:00  ④ 生成 Top10 报告
           → 非纯销量排序（见综合排序公式）
           → 输出：排名/类目/标题/价格/佣金/评分/置信度/抖音理由/风险/推荐标记
           → 保存到 reports/daily/YYYY-MM-DD.md

           ✅ 人工确认：确认哪些商品进入内容生成池

每周一  ⑤ 复盘与权重优化
           → 对比「入选商品」的实际抖音数据
           → 人工确认是否需要调整权重
           → 版本化记录（score_weights 表）
```

## D. Top10 输出格式

```
==========================================
 🏆 Top10 候选商品 · YYYY-MM-DD
 垂类：办公居家桌面有趣小摆件
==========================================

#1 【细分类目】
📦 商品标题（≤50字）
💰 ¥XX.X | 佣金X.X%(¥X.XX/件) | 销量: XXXXX
📊 综合评分: XX.X/100 | 置信度: XX%
📐 维度细项: 抖音适配X/视觉X/低决策X/佣金X/竞争X
🎬 抖音适配理由: [具体理由，说明为何适合短视频]
⚡ 风险提示: [具体风险，包括合规/视觉落差/供给等]
🎯 是否推荐进内容生成池: ✅推荐 / ⚠️待定 / ❌不推荐
```

**置信度计算逻辑：**
- 基础值 50%
- 抖音适配≥9分 → +20%
- 抖音适配7-8分 → +10%
- 视觉强度≥8分 → +10%  
- 有真实佣金数据 → +10%
- 无精确销量数据 → -10%
- 上限 95%（不满分，因为无法验证实际销售）
