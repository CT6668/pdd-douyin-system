# 内容策划系统设计文档 v1.1
> 垂类：办公居家桌面有趣小摆件
> 更新日期：2026-03-08
> v1.1 变更：新增小红书图文笔记平台支持（内挂商品卡 + 评论区推广链接）

## 平台概览

| 平台 | 内容形式 | 带货方式 | 每商品生成数量 |
|------|---------|---------|-------------|
| 抖音 | 竖屏短视频（15s） | 橱窗商品卡 | 4套脚本 |
| 小红书 | 图文笔记（6张图） | 内挂商品卡 / 评论区推广链接 | 4套图文笔记 |

**小红书推广链接说明：**
- **内挂商品卡**（优先）：需加入小红书联盟，商品卡直接嵌入笔记，用户点击可跳转购买，转化路径最短
- **评论区推广链接**：发布后手动在评论区置顶多多进宝/联盟推广链接，灵活但需每次手动操作
- **个人主页链接**：流量最低，备选方案
- ⚠️ 小红书正文内不能放任何外链，违规会被限流或删号

## A. 脚本模板

### 通用数据结构

```
ScriptResult {
  product_id      : int          # 商品DB ID
  script_type     : str          # pain_point / scene / contrast / list
  title           : str          # 视频标题（≤20字，含核心关键词+情绪词）
  cover_copy      : str          # 封面大字（≤10字，视觉冲击，不用标点）
  hook_3s         : str          # 前3秒钩子台词（疑问/数字/反转，≤15字）
  storyboards     : List[SB]     # 分镜列表，总时长13-15秒
  full_subtitle   : str          # 完整字幕文本（拼接）
  voiceover       : str          # 完整口播稿（可选，可与字幕不完全相同）
  cta             : str          # 行动号召（≤15字，含价格+入口）
  pub_time        : str          # 推荐发布时段
  mount_suggest   : str          # 挂载建议
  compliance_notes: str          # 合规检查项
}

Storyboard {
  index      : int    # 第几段（1起）
  duration_s : float  # 时长（秒）
  shot_desc  : str    # 画面描述（拍摄执行用）
  subtitle   : str    # 该段字幕
  voiceover  : str    # 该段口播（可为空）
}
```

### 分镜时间结构（总15秒）

```
[0~3s]   钩子段   ← 必须有强烈钩子，决定完播率
[3~8s]   展示段   ← 商品核心卖点，视觉最强时刻
[8~13s]  深化段   ← 强化情绪/场景/对比
[13~15s] CTA段    ← 价格+行动指令，简短有力
```

## B. 封面文案模板

### 封面3原则
1. **≤10字**（手机屏幕上一眼看完）
2. **有情绪词**（治愈/封神/绝了/太好看了）
3. **不能是纯商品名**（要给人"我要看"的欲望）

### 封面文案公式

| 类型 | 公式 | 示例 |
|------|------|------|
| 痛点型 | 「负面现状」→「变化结果」 | 死气沉沉的桌面 → 封神了 |
| 场景型 | 「场景词」+「情绪词」 | 打工人桌面 治愈神器 |
| 反差型 | 「价格」+「超预期结果」 | ¥19买到这个 |
| 清单型 | 「数字」+「价值承诺」 | 3个理由选它 |

### 封面禁止事项
- ❌ 不用"最好/第一/绝对"等绝对化用语
- ❌ 不用"保证/承诺/治疗/功效"等违规词
- ❌ 不用夸大宣传（"让你暴富的招财猫"）
- ✅ 可以用 emoji，增加视觉层次
- ✅ 价格数字是合规的强力武器

## C. 字幕模板

### 字幕3原则
1. **每段≤15字**（竖屏阅读速度，超过看不完）
2. **口语化**（像人说话，不像广告词）
3. **每段有情绪推进**（疑问→发现→惊喜→行动）

### 字幕节奏模板

```
第1段（钩子）：「反问/悬念/数字」
  例：你的桌面是不是也这样？
  例：才19块能买到什么？

第2段（转折）：「发现/改变的瞬间」
  例：直到我发现了它
  例：打开包装愣住了

第3段（展示）：「核心卖点，情绪最高点」
  例：这质感真没想到
  例：看一眼就心情好了

第4段（CTA）：「价格+购买指令」
  例：橱窗19元 直接下单
  例：评论区链接 数量不多
```

### 字幕合规检查
- 「治愈」→ 合规（情绪词，非功效词）
- 「治疗」→ ❌ 违规
- 「减压」→ 合规（描述功能）
- 「包治百病」→ ❌ 违规
- 「性价比高」→ 合规
- 「全网最低价」→ ❌ 违规

## D. 4种脚本类型生成规则

### 类型一：痛点型（pain_point）

**适用商品**：解压类、改善工位氛围类、送礼类
**核心逻辑**：先放大痛点，再用商品解决
**情绪弧线**：焦虑 → 发现 → 释然 → 行动

```
钩子词库：
- "你的桌面是不是也毫无生气？"
- "每天对着这张桌子，多没劲啊"
- "上班没状态，是因为工位太无聊了"

商品出现词库：
- "直到我发现了它"
- "朋友推荐了这个之后"
- "无意间刷到了这个"

效果词库（合规版）：
- "每次看到它心情就莫名好一些"
- "工位氛围感一下子就来了"
- "同事都来问我在哪买的"
```

**分镜结构**：
1. [3s] 展示问题现状（空桌、乱桌、无聊感）
2. [3s] 商品入画（手拿商品，慢动作）
3. [5s] 商品展示+使用效果（360°+桌面整体效果）
4. [4s] 情绪升华+价格CTA

---

### 类型二：场景型（scene）

**适用商品**：治愈类、装饰类、打工文化相关
**核心逻辑**：构建一个"我也想要这种生活"的场景
**情绪弧线**：代入 → 共鸣 → 向往 → 行动

```
场景词库（办公场景）：
- "每天在这张桌子前坐8小时"
- "午休刷手机，工位也值得有点氛围"
- "打工人，工位是第二个家"

场景词库（居家场景）：
- "周末在家办公，桌面得有点仪式感"
- "书桌上放什么，决定了心情好不好"

氛围升华词库：
- "自从放上它，工作间隙总忍不住看几眼"
- "小小的一个，但幸福感真的不一样了"
- "送自己一个小惊喜，不过分吧"
```

**分镜结构**：
1. [3s] 建立场景（桌面/工位环境，自然光）
2. [3s] 商品融入场景（轻轻摆上去）
3. [5s] 整体效果展示（环境+商品，氛围感镜头）
4. [4s] 情感升华+价格CTA

---

### 类型三：反差型（contrast）

**适用商品**：颜值超预期类（水晶/沙漏/艺术摆件）、低价高质感
**核心逻辑**：用"不如预期"建立低预期，再用"远超预期"收割
**情绪弧线**：质疑 → 意外 → 惊喜 → 分享冲动

```
质疑钩子词库：
- "X块钱的东西能有多好看？"
- "网购桌面摆件，我以为又踩雷了"
- "看着也不像X块的东西"

反转词库：
- "打开包装的瞬间我愣住了"
- "比图片好看十倍"（注意：不要夸大到不实）
- "这质感和颜值真的没想到"

超值感词库（合规）：
- "X块买到这个，说出去没人信"
- "同价位里找不到第二个"（不用"全网最好"）
- "性价比真的炸了"
```

**分镜结构**：
1. [3s] 质疑/低预期铺垫（手拿包裹，怀疑表情）
2. [4s] 开箱/摆放瞬间（慢动作，情绪爆发）
3. [5s] 全方位展示（颜值+质感+桌面效果）
4. [3s] 超值总结+价格CTA

---

### 类型四：清单型（list）

**适用商品**：有多个明确卖点的商品、送礼场景
**核心逻辑**：用数字框架降低决策成本，逐条攻破
**情绪弧线**：好奇（数字钩子）→ 认同 → 认同 → 认同 → 行动

```
数字钩子词库：
- "3个理由，让你忍不住买它"
- "买它之前，先看这4点"
- "为什么我回购了3次？"

卖点维度（根据商品选3个）：
颜值维度：放上去直接出大片
实用维度：不只是摆设，真的好用（解压/计时）
价格维度：只要X块，不到一杯奶茶钱
情感维度：送自己/送朋友都合适
稀缺维度：这款颜色快断货了（仅在真实情况使用）
```

**分镜结构**：
1. [2s] 数字钩子（大字幕+手势）
2. [4s] 卖点一展示（最强视觉卖点）
3. [4s] 卖点二展示（实用/情感卖点）
4. [5s] 卖点三+价格CTA（价格是最后一击）

## 商品类目特化规则

不同类目商品有不同的最优脚本策略：

| 商品类目 | 最优脚本类型 | 核心视觉卖点 | 禁忌 |
|---------|------------|------------|------|
| 流沙画/沙漏 | 反差型 > 场景型 | 流沙流动慢动作 | 不说"减压治愈百病" |
| 水晶发财树 | 场景型 > 清单型 | 光折射特写 | 不承诺"带来财运" |
| 解压玩具 | 痛点型 > 反差型 | 操作画面（捏/转） | 不说"包治焦虑" |
| 永生花/干花 | 场景型 > 清单型 | 颜值+氛围感 | 不说"永不凋谢100年" |
| 招财猫摆件 | 清单型 > 场景型 | 细节工艺 | 不承诺"必然带财" |

## 合规红线一览（必须人工确认）

| 违规表达 | 合规替代 |
|---------|---------|
| 治疗焦虑/抑郁 | 让心情好一点点 |
| 包治/保证 | 试试看 |
| 最好/第一/绝对 | 个人觉得很好 |
| 全网最低价 | 性价比不错 |
| 点击购买必赚 | 值得入手 |
| 永不凋谢（夸大） | 保存时间较长 |
| 必然招财/保证发财 | 寓意美好 |

## E. 小红书图文笔记专项规范

### 图文结构（6张图标准模板）

```
第1张（封面）: 商品最美角度 + 封面大标题（≤20字）+ 副标题（≤10字）
              → 决定点击率，是最重要的一张
第2张（对比/场景）: 前后对比 或 产品入场仪式感图
第3张（细节特写1）: 商品正面/核心卖点，强调质感
第4张（细节特写2）: 局部工艺/材质/使用细节
第5张（氛围图）: 桌面整体效果，体现生活方式
第6张（CTA图）: 大字显示价格 + 购买引导文案
```

### 正文结构规范（≤1000字）

```
段落1（钩子）: 1-2句话，引发共鸣或好奇
段落2（故事/场景）: 3-5句，构建使用场景，口语化
段落3（卖点清单）: 用✅/🌿/💎等emoji分条，3-4个卖点
段落4（价格/总结）: 1-2句，强调价值感
段落5（CTA）: 1句，引导评论/链接操作
免责声明: "仅代表个人体验，效果因人而异"（防违规）
```

### 话题标签策略（10个）

```
基础类（必选2-3个）: #桌面好物 #工位布置 #办公桌摆件
品类类（必选1-2个）: 根据商品类目选，如 #流沙画 #水晶摆件
场景类（必选1-2个）: #打工人 #上班族必备 #居家好物分享
互动类（可选1-2个）: #开箱测评 #购物分享 #种草清单
```

### 小红书推广链接操作流程

```
发布前确认：
  ① 该商品是否已申请小红书联盟商品？
     → 是：使用「内挂商品卡」，在发布时直接关联
     → 否：使用「评论区推广链接」

  ② 评论区推广链接操作（发布后30分钟内完成）：
     1. 复制多多进宝推广链接
     2. 在笔记评论区发布链接
     3. 长按该评论 → 「置顶评论」
     4. 正文可提示「评论区第一条有链接」

  ③ 禁止行为：
     ❌ 正文/标题内放任何 http 链接
     ❌ 导流到微信/其他平台
     ❌ 提及竞品平台名称
```

### 小红书合规特别说明

| 小红书特有规则 | 说明 |
|-------------|------|
| 禁止正文放外链 | 任何 http/https 链接都不能出现在正文/标题/图片 |
| 禁止导流竞品 | 不能提「淘宝/京东/拼多多/微信」等平台引流 |
| 内挂需联盟资质 | 内挂商品卡需加入小红书蒲公英联盟或买家联盟 |
| 真实体验声明 | 建议末尾加「仅个人体验」避免广告违规 |
| 避免营销感过强 | 小红书用户排斥硬广，要保持「真实种草」调性 |
